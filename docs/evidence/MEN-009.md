# MEN-009 clean-room copy vertical slice evidence

## Scope

This change adds one original, low-risk copy capability as five canonical resources:

- role: `role.copy-strategist@1.0.0`;
- skill: `skill.message-clarity-review@1.0.0`;
- task: `task.draft-campaign-message@1.0.0`;
- workflow: `workflow.reviewed-campaign-message@1.0.0`;
- module: `module.copy-foundation@1.0.0`.

Each canonical resource has a separate approved `ProvenanceRecord`, for ten versioned catalog resources in total.

The slice drafts one message from an approved brief and evidence set. It cannot publish, call external tools, invent evidence, or replace a runtime identity. The workflow requires a human gate before handoff.

## Clean-room record

The canonical wording was created from the MENAXVI target contracts and MEN-009 acceptance criteria. Quarantined copy squads were inspected only to identify unsafe patterns that must not be retained. No legacy prose, named persona, legacy agent identifier, champion example, named persuasion framework, or runtime command was migrated.

The five provenance declarations are in `catalog/provenance/`. Each record names one subject file and stores its SHA-256 digest.
