# Reviewed campaign-message example

These files provide valid input and result shapes for the manual workflow tutorial.

- `inputs.json` contains a non-sensitive sample brief and evidence statement.
- `results.json` demonstrates the required result structure for execution ID `tutorial-001`.

Run the complete example through [the customer workflow tutorial](../../docs/customer/WORKFLOW-TUTORIAL.md). The message text and approval evidence are illustrative. Replace them with reviewed execution data before relying on a record.
