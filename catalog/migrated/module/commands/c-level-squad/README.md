# Executive Strategy Council

Professional decision-support module for evidence-based business strategy. Roles are capability-defined and do not impersonate public figures or claim executive authority.

## Use

1. Start with `diagnose`.
2. Select the smallest set of relevant functional roles.
3. Execute the matching task or workflow.
4. Run `review` before a consequential decision.

## Boundaries

Outputs are advisory. Decision owners remain accountable. Legal, financial, employment, privacy, security, and regulated matters require qualified review.
