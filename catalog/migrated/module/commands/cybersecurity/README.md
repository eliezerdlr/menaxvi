# Authorized Defensive Security Operations

This module replaces the legacy offensive-security squad with governed defensive workflows. It supports security posture assessment, application and mobile review, vulnerability management, detection engineering, incident response, hardening, and evidence review.

## Exclusions

No exploit catalogs, weaponized commands, payload delivery, credential attacks, automated password guessing, persistence, evasion, personal profiling, or unapproved active testing are provided. Requests outside these boundaries stop at an authorization and safety review.

## Workflows

- `wf-defensive-assessment.yaml`: owner-approved evidence collection, control review, hardening, and remediation verification.
- `wf-incident-response.yaml`: evidence-preserving triage, containment, recovery, and lessons learned.
