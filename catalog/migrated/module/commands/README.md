# MENAXVI capability corpus

MENAXVI provides governed, provider-neutral roles, tasks, workflows, knowledge resources, and adapters. Canonical capabilities are stored under `catalog/`; preserved source evidence remains outside the runtime catalog for audit and rollback.

Use `migrations/legacy-corpus.map.json` as the source-to-target disposition ledger. A capability is runtime eligible only after clean-room remediation, parity evidence, and approved review. Vendor-specific installation instructions and persona-based authority claims are not part of the canonical product.
